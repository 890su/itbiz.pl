# План SEO, контента и запуска Google Ads

## Цель

Получить первые квалифицированные B2B-заявки в Варшаве через узкие поисковые
интенты, не отправляя платный трафик на общие или конфликтующие страницы.

План относится только к ITBIZ.PL. Междоменная каннибализация в его объём не
входит.

## Этап 1. Устранение внутренних SEO-конфликтов

- [x] Развести назначение главной, каталога услуг, страницы зоны обслуживания и
      постоянной IT-поддержки во всех языках.
- [x] Закрепить аварийные запросы за страницей аварии сети, а плановую
      диагностику — за отдельной страницей диагностики.
- [x] Закрепить проектирование и внедрение Wi‑Fi за общей страницей Wi‑Fi, а
      измерения и аудит — за страницей аудита малого офиса.
- [x] Закрепить новую кабельную сеть за страницей LAN, ремонт одной линии — за
      страницей LAN-розетки, а обслуживание шкафа — за страницей rack.
- [x] Закрепить диагностику неработающего мониторинга за аварийной страницей, а
      новые трассы к камерам — за страницей кабельной инфраструктуры CCTV.
- [x] Оставить IT-переезд отдельным событийным интентом: два адреса, перечень
      рабочих мест, ответственность за транспорт и план запуска.
- [x] Сделать широкие страницы услуг не менее конкретными, чем новые узкие
      посадочные: индивидуальный CTA, условия, процесс и подсказка формы.
- [x] Сохранить одну задачу и один основной поисковый интент для каждой услуги.

## Этап 2. Мультиязычная согласованность

- [x] Синхронно внести изменения в PL, RU, EN и UK.
- [x] Не смешивать языки в title, H1, CTA и полях формы.
- [x] Проверить self-canonical, reciprocal hreflang и `x-default`.
- [x] Не направлять рекламу одного языка на страницу другого языка.
- [x] Оставить `adEligible: false` до отдельного коммерческого и языкового
      допуска каждой посадочной.

## Этап 3. Конверсионная готовность

- [ ] Подтвердить публичный телефон, часы приёма заявок и реальный порядок
      обратной связи.
- [ ] Настроить немедленное уведомление о новой заявке, сохранив D1 как основной
      журнал обращений.
- [ ] Упростить аварийный сценарий обращения на мобильном устройстве.
- [ ] Зафиксировать основную конверсию только после успешного ответа API.
- [ ] Добавить импорт квалифицированного и оплаченного лида без передачи лишних
      персональных данных.

## Этап 4. Ограниченный рекламный запуск

- [ ] Начать с польских Search-кампаний по независимым GEO-ячейкам: юг, центр и
      запад Варшавы, Piaseczno-коридор и Janki/Raszyn/Dawidy Bankowe.
- [ ] Первая группа — авария сети компании.
- [ ] Вторая группа — авария IP-видеонаблюдения компании.
- [ ] Третья группа — IT-переезд офиса.
- [ ] Четвёртая группа — конкретная неисправность LAN.
- [ ] Пятая группа — аудит и диагностика Wi‑Fi малого офиса.
- [ ] Отдельным экспериментом проверить новую сеть LAN.
- [ ] Добавить paused-тесты: порядок в rack, кабели CCTV и экран переговорной;
      не смешивать их с аварийными интентами.
- [ ] Не запускать Display, Search Partners, Demand Gen и Performance Max до
      подтверждения качества Search-лидов.
- [ ] Проверять Search Terms ежедневно в первую неделю и расширять минус-слова.

## Этап 5. Масштабирование

- [ ] Запускать RU, EN и UK отдельно только после языковой проверки посадочных и
      объявлений.
- [ ] Включать и останавливать каждый язык и GEO-ячейку независимо; малые
      населённые пункты объединять в непересекающиеся кластеры с Presence-only.
- [ ] Переносить бюджет между услугами по стоимости квалифицированной заявки, а
      не по CTR или количеству отправленных форм.
- [ ] Добавлять широкие услуги и постоянную IT-поддержку только после появления
      проверенных коммерческих условий и доказательств доверия.

## Критерии готовности страницы к рекламе

Страница получает рекламный допуск только если:

1. выше первого экрана ясно указаны B2B-аудитория, задача, география и следующий
   шаг;
2. ключевое слово, объявление, H1, CTA и выбранная тема формы описывают одну и ту
   же услугу;
3. опубликованы только подтверждённые сроки, цены, материалы и ограничения;
4. форма и её уведомления проверены в production;
5. настроена основная конверсия и сохранение источника лида;
6. страница не пересекается с другой рекламируемой страницей по основному
   поисковому намерению;
7. язык объявления совпадает с языком посадочной.
