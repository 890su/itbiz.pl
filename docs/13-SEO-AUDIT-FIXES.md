# Исправления аудита seo-landing

Дата: 2026-10-16.

Исправляются HTTPS-redirect, контраст CTA в тёмной теме, ARIA общего шаблона,
наложение H1 на схему, семантическая разметка, локализация подписей услуг,
мобильное меню, share-preview, favicon и блокирующая загрузка ресурсов.
Дополнительно исправлен отказ формы для `cctv-emergency`.

## Данные и внешние зависимости

- `Organization`: GOODSERVICE sp. z o.o., NIP 5272714609, утверждённые телефон и
  email. `LocalBusiness`, адрес, часы и обещания скорости не добавляются.
- `WebSite`: только корень домена. `WebPage`, `BreadcrumbList` и `Service`
  связаны стабильными `@id`. JSON-LD сериализуется с экранированием `<`.
- PNG favicon и share-preview получены из существующего favicon и утверждённых
  реквизитов. Источник: `public/favicon.svg`, `src/data/company.ts`.
  Воспроизведение: `node scripts/generate-brand-images.mjs`. Внешние фотографии
  и сторонние права на изображения не используются.
- Стабильные URL PNG используют revalidation, без `immutable`.
- Собственный CSS включается в HTML. Синхронный `theme.js` (200 байт исходного
  кода) сохраняется для применения сохранённой темы до первого отображения.
  Google Ads bootstrap загружается с `defer`, внешние теги Google - только после
  advertising consent. Модуль согласий остаётся первым источником выбора.
- Cloudflare Turnstile: `https://challenges.cloudflare.com/turnstile/v0/api.js`,
  изменяемый URL поставщика, поэтому SRI неприменим. Инициализация при приближении
  формы на 400px или фокусе в форме; на старых браузерах без IntersectionObserver
  используется обычная загрузка. CSP: script-src/frame-src/connect-src
  `https://challenges.cloudflare.com`. Referrer: strict-origin-when-cross-origin.
  Turnstile сам управляет challenge iframe и служебными запросами. Проверка
  токена на сервере остаётся обязательной для production.
- Google tag: `https://www.googletagmanager.com/gtag/js?id=AW-18394870871`,
  изменяемый URL поставщика, без стабильного SRI. Назначение - измерение рекламы,
  владелец - оператор ITBIZ.PL, включение - только advertising consent.
  CSP домены перечислены в `public/_headers`. Содержимое формы и контакты
  посетителя в tag не передаются.

## Границы проверки

Реальную доставку production-заявки, немедленное уведомление, импорт UTM/gclid
и серверную идемпотентность нужно проверять в отдельном workflow при настройке
измерения/обработки лидов. Этот выпуск не меняет структуру D1 и настройки
внешнего получателя. Показ кампаний из-за этих изменений не включается.

Лабораторный Lighthouse не подтверждает полевые Core Web Vitals или индексацию.
JSON-LD сам по себе не подтверждает Google rich-result eligibility.

## Проверки перед публикацией

- 29 модульных и 33 браузерных теста прошли. Регрессии охватывают все
  опубликованные serviceId, HTTPS, Escape/focus, no-JS навигацию, пересечение
  H1 со схемой в четырёх языках и отложенный Turnstile.
- 85 HTML-файлов сборки (84 страницы и 404) проверены на ссылки,
  canonical/hreflang, данные компании и Service/BreadcrumbList.
- W3C Nu и Schema.org Validator проверили preview главной и по одной странице
  услуг PL/RU/EN/UK: ошибок и предупреждений нет.
- Снимки preview проверены при 320/390/768/1280/1920px в светлой и тёмной теме.
  Контраст основных кнопок: light 5,27:1, dark 7,71:1.
- Артефакты находятся в игнорируемом `reports/seo-landing-2026-10-16/`:
  `preview-verification.json`, `schema-summary.json`, `schema-*.json`, PNG.
  Файлы ответов валидаторов содержат только публичный HTML сайта.
- Детектор Impeccable отмечает существующую сетку и полосу у callout как
  стилистические замечания. Эти элементы относятся к сохранённому дизайну;
  данный выпуск не заменяет его.
