# Approved logo — 31 October 2026

The owner selected the first symbolic proposal, a network joining an
organisation's work points, then requested publication. The mark uses the
existing blue #3b82f6, with an outlined Manrope wordmark. Dark-panel artwork
is used by both navigation variants and the existing dark footer, in both
page themes. Header logo links retain their localized accessible names.

Assets live in `public/assets/brand/20261031/`. `BrandLogo.astro` supplies the
same SVG to the mobile header, desktop sidebar and footer. Its intrinsic
dimensions reserve space; responsive rules keep the language/theme/menu
controls available at small widths. The SVG viewBox trims transparent
presentation padding without changing approved contours.

The base layout includes versioned SVG/ICO favicons, Apple touch icon and a
web manifest. The social preview and Organization image reference a matching
1200×630 PNG. Earlier cached assets remain available; the root favicon
fallbacks contain the new mark. URL, title, description, canonical/hreflang,
forms, measurement and Worker bindings are unchanged.

Use the light horizontal master for future white-background applications.
The colour variants were reviewed in the local brand kit. Manrope's SIL OFL
licence is saved in `docs/brand/Manrope-OFL.txt`; display requires no font.
