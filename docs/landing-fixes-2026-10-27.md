# Follow-up to the compact landing audit

The background now pauses whenever the separate enquiry dialog is open, including
when its close button receives focus. Enquiry examples and simulated typing
respect reduced motion; normal automatic scrolling is retained. Keyboard focus
within the example list pauses its movement. Loop geometry is measured on resize
and state changes rather than on every animation frame.

Turnstile verification has an eight-second timeout and catches network, malformed
JSON and upstream errors. Failed verification cannot create a stored enquiry;
the existing form retains its text and can retry. A successful response still
requires accepted storage or the configured webhook. The existing approved
share image is included in Organization metadata.

New regressions cover reduced-motion selection, dialog pause, failed verification,
verified storage and storage failure. The original design, compact copy, all
routes and four locales are retained.

Google Rich Results Test on the production CCTV page found three valid items
(breadcrumbs, organization and business interpretation), with no critical errors.
Its optional company-address suggestion does not justify publishing an unverified
address. No search appearance is guaranteed. A public, approved brand image is
used to resolve its optional image suggestion.

Raw follow-up evidence is kept locally in `reports/seo-landing-2026-10-27/`.
The prior audit remains a historical baseline, not a claim about follow-up checks.
