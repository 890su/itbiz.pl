```text
Что не входит:
Формат: on-site / remote / mixed:
География:
Минимальная единица заказа:
Как рассчитывается цена:
Реальный срок ответа:
Реальный срок начала работ:

```

Без этой карточки страница остаётся draft/noindex/adEligible=false.

## 4. Реализации

Публикационный checklist:

- [ ] проект действительно выполнен;
- [ ] факты подтверждены исполнителем;
- [ ] результат измерим или описан без преувеличения;
- [ ] клиент разрешил название/логотип либо полностью анонимизирован;
- [ ] фото очищены от лиц, адресов, SSID, ключей, экранов и документов;
- [ ] указаны связанные service/solution IDs;
- [ ] нет consumer positioning;
- [ ] перевод не добавляет отсутствующих в оригинале фактов.

## 5. Инструкции

Инструкция должна отвечать на один безопасный вопрос и включать:

- цель;
- для кого материал;
- требования/предупреждения;
- шаги;
- проверку результата;
- когда остановиться и обратиться к специалисту;
- связанные решения и услугу без агрессивного CTA;
- дату проверки актуальности.

Контент 890.by не переносится и не переписывается через автоматический перевод.

## 6. Локализация

Порядок:

1. Утверждается польский source content.
2. Для языка проводится отдельное keyword research.
3. Перевод адаптирует запросы и терминологию для компаний в Польше.
4. Названия польских систем/районов сохраняются корректно.
5. Native/editorial review проверяет рекламируемые страницы.
6. Только после review страница получает `published` и hreflang.

Переводы не обязаны быть дословными, но scope, exclusions, цены и юридические
факты должны оставаться эквивалентными.

## 7. Tone of voice

Польский:

- профессиональный, прямой, без канцелярита;
- `firma`, `biuro`, `organizacja`, `zakres`, `ustalenia`, `wdrożenie`;
- короткие активные предложения;
- технический термин объясняется при первом использовании.

Другие языки сохраняют тот же уровень: не бытовая «компьютерная помощь», а
понятное обслуживание инфраструктуры организации.
